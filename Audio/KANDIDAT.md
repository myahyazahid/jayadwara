# Kandidat SFX Episode 1

Hasil `Tools/sfx_shortlist.py`. Semua **CC0** (boleh komersial, tanpa wajib kredit). Dengarkan `k1`–`k3` per slot, pilih satu, lalu catat di kolom **Pilih** (atau bilang ke Claude).

- Kenney: satu kandidat = satu set variasi (pakai semua di Sound Cue *Random*).
- Freesound: dari preview HQ (MP3 ±128 kbps). Untuk final, download file asli lewat link (perlu login).
- Ambien/musik dipotong 30 detik + fade out, hanya untuk audisi.
- Kolom ukur (file sumber, kanal digabung): durasi · peak dBFS · RMS dBFS · **bass** = porsi energi < 150 Hz · centroid (Hz, makin tinggi makin terang). WAV hasil sudah dibatasi peak -1 dBFS.
