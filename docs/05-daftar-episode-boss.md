# 05 — Daftar Episode & Boss (Ep 1–50)

Boss disusun dari yang **terlemah / kurang terkenal** (Ep 1) sampai **terkuat** (Ep 50).
Tanda ⚠️ = perlu penanganan hati-hati secara budaya — lihat [06-referensi-mitologi.md](06-referensi-mitologi.md#panduan-sensitivitas-budaya).

## Ringkasan Scope

- **43 boss mitologi unik** + story boss (Dwarapala Kala, Dwarapala Kembar ×2) + 1 boss rush + boss multi-fase (Bedawang Nala ×2, Batara Kala ×3).
- Durasi target per episode: **20–40 menit**.

### Pengelompokan rig / skeleton (hemat produksi)

| Grup Rig | Boss |
|---|---|
| Buto / humanoid raksasa | Gergasi, Buto Terong, Buto Pragalba, Buto Rambut Geni, Buto Cakil, Buto Ijo, Geunteut, Genderuwo |
| Humanoid kepala hewan | Mahesa Suro, Lembu Suro |
| Kepala terbang | Palasik, Kuyang, Kala Rahu |
| Ular / naga | Nyai Blorong, Juata, Antaboga |
| Reptil berkaki empat | Buaya Siluman, Ora, Bedawang Nala (skala berbeda) |
| Dwarapala | Jayadwara, Dwarapala Kala, Dwarapala Kembar |
