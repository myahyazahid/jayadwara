# 09 — Product Brief

> Pengganti PRD untuk konteks game: menjawab *untuk siapa*, *di mana dijual*, dan *bagaimana mengukur sukses*.
> Detail desain ada di GDD (dokumen 01–08).

## Ringkasan Produk

| | |
|---|---|
| **Judul** | JAYADWARA: Guardian of the Seven Gates |
| **Genre** | Action-adventure episodik, *kyodai hero* (giant hero) |
| **Engine** | Unreal Engine 5.6.1 (C++ + Blueprint) |
| **Platform** | **PC — Steam** |
| **Gaya visual** | **Stylized** |
| **Bahasa** | Audio/teks Indonesia + subtitle Inggris |
| **Tim** | **Solo developer** + Claude (C++, dokumen, tooling) |
| **Kapasitas** | Sambilan, **±10–15 jam / minggu** |
| **Model rilis** | Premium, per season. Season 1 = Arc 1 (Ep 1–10) sebagai **Early Access** |

## Elevator Pitch

> Seorang agen pesilat menyatu dengan Dwarapala, penjaga gerbang kuno yang dulu dianggap monster, untuk melawan makhluk mitologi Nusantara yang bangkit sebagai raksasa — sambil menjaga agar kota yang ia lindungi tidak ikut hancur.

## Target Pemain

| Segmen | Kenapa Tertarik |
|---|---|
| **Penggemar tokusatsu / kaiju** (global, kuat di Asia) | Genre kyodai hero jarang punya game action modern |
| **Pemain action game** (beat 'em up, character action) | Combat silat dua skala, boss fight episodik |
| **Pemain Indonesia & Asia Tenggara** | Representasi budaya dan mitologi lokal, bahasa Indonesia |
| **Pencinta folklore / horor Asia** | Monster dari mitologi yang jarang diangkat |

**Rating konten (target)**: remaja — kekerasan fantasi dan unsur horor, tanpa gore eksplisit.

## Nilai Jual Unik (USP)

1. **Game kyodai hero pertama berbasis mitologi Nusantara.**
2. **Investigasi yang berdampak** — petunjuk di mode manusia membuka kelemahan boss di mode raksasa.
3. **Meter sinkronisasi** — kemenangan diukur dari seberapa baik kamu melindungi kota, bukan cuma mengalahkan monster.
4. **Narasi wayang kulit** di setiap pembuka episode.
5. **Penjaga yang ambigu** — pahlawan yang menyimpan sifat monster di dalam dirinya.

## Model Bisnis

| Aspek | Rencana | Status |
|---|---|---|
| Harga Season 1 (Early Access) | Kisaran harga indie kecil; tentukan setelah vertical slice | Terbuka |
| Season berikutnya | Update gratis selama Early Access **atau** DLC/season pass | Terbuka |
| Demo | Demo gratis berisi Episode 1 untuk Steam Next Fest | Direncanakan |
| Biaya platform | Steam Direct fee per judul | Wajib |

## Ukuran Sukses

| Tahap | Indikator |
|---|---|
| Vertical slice | Dapat dimainkan 20–30 menit dari awal sampai akhir; feedback playtester positif soal combat & rasa skala |
| Halaman Steam | Wishlist terus bertambah setiap bulan sejak halaman dibuka |
| Demo / Next Fest | Rasio wishlist dari pemain demo; masukan untuk perbaikan |
| Early Access | Review Steam mayoritas positif; penjualan cukup untuk membiayai produksi Season 2 (aset, audio, kemungkinan rekrut) |

*Angka target spesifik (jumlah wishlist, penjualan) ditentukan setelah halaman Steam berjalan dan ada data pembanding.*

## Risiko Utama

| Risiko | Dampak | Mitigasi |
|---|---|---|
| **Scope terlalu besar** untuk solo sambilan | Proyek tidak selesai | Rilis per season, mulai dari vertical slice, potong fitur tanpa ragu |
| **Produksi aset 3D** (karakter, monster) | Bottleneck terbesar solo dev — Claude tidak bisa membuat model 3D | Gaya stylized, aset Fab, pakai ulang rig, commission karakter kunci |
| **Animasi silat** | Butuh animasi khusus | Mixamo untuk prototype; video-mocap / commission untuk final |
| Dianggap "tiruan Ultraman" | Reputasi & legal | Patuhi daftar larangan IP; tonjolkan identitas Nusantara |
| Sensitivitas budaya | Reaksi negatif komunitas | Ikuti panduan di dokumen 06; review oleh budayawan |
| Performa destruction | FPS turun | Batasi jumlah objek hancur; uji sejak prototype |
| Motivasi solo jangka panjang | Burnout | Milestone kecil yang terlihat hasilnya; bagikan progres (devlog) |
