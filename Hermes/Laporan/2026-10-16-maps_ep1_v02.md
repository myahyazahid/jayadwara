### Temuan V0 (dicatat, tidak diperbaiki)
1. **TOL_Pilar7 — selisih tanah di tapak 2,76 m.** Diketahui di panduan V1 ("diketahui: `TOL_Pilar7` ±2,8 m, boleh"). Tidak diperbaiki.
2. **Generator crash di console Windows (cp1252)** saat mencetak karakter ★ → `UnicodeEncodeError: 'charmap' codec can't encode character '\u2605'`. **Bukan bug data**, hanya encoding stdout. Dijalankan dengan `PYTHONIOENCODING=utf-8` (+ `python -X utf8`) → lulus. **Catatan developer:** kalau `buat_layout_ep01_v02.py` dijalankan dari cmd/PowerShell bawaan Windows, set `PYTHONIOENCODING=utf-8` dulu (atau jalankan lewat Git Bash) supaya baris rute tidak crash saat print.
3. **`git status` sempat "modified"** pada `Art/Level/ep01_layout_v02.json` sesudah generator, **tetapi isinya byte-identik** (57808 byte; `git diff` kosong). Penyebab: line ending — generator menulis **LF**, sedangkan checkout Windows (`core.autocrlf=true`) memakai **CRLF** (`git ls-files --eol`: v01 `w/crlf`, hasil generator `w/lf`). Diselesaikan dengan `git restore` (kembali ke `w/crlf`) → `git status` bersih. **Tidak ada perbedaan data** antara generator dan repo; jadi kriteria "git status tetap bersih" terpenuhi setelah restore eol.
